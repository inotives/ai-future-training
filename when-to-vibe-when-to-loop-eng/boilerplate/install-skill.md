## Install the Trinary Agents skill

After copying this boilerplate into your working project, install the skill from the project root before starting the learning activities:

```sh
npx skills add https://github.com/inotives/trinary-agents --skill trinary-agents
```

Choose project-level installation to use the skill for this lesson. Choose global installation if you want Trinary Agents available in all your projects. After project-level installation, `.agents/` or `.claude/` should contain `skills/trinary-agents` and its assets. Make sure your coding agent can access the installed skill, then continue with the lesson.
