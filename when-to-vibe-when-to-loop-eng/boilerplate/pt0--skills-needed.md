# Skills needed for this learning

After copying this boilerplate into your working project, install the Trinary Agents skill from the project root before starting the learning activities:

```bash
npx skills add https://github.com/inotives/trinary-agents --skill trinary-agents
```

Follow the CLI prompts to install the skill. 

Choose project level installation, if you just want to follow this lesson. if you want trinary-agents to be available to your agents on all sessions from now onward, use global instead of project level installation. 

After you choose project level installation, you should see .agents or .claude folder created with skills/trinary-agents along with its assets. 

Make sure to ask your coding agent can access the installed `trinary-agents` skill, then continue with the lesson.
