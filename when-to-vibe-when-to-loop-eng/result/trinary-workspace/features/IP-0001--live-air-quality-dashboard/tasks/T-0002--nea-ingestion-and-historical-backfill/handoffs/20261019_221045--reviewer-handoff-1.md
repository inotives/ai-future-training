## Findings

- `server/ingestion.js:146` defaults `backfillDelayMs` to 1,000 ms, and `importHistory` uses that delay between each sequential provider request (`server/ingestion.js:205-211`). The official [data.gov.sg API rate limits](https://guide.data.gov.sg/developer-guide/api-overview/api-rate-limits) state the unauthenticated v2 Real-time API limit is 6 calls per 10 seconds. A one-second interval permits up to 10 calls per 10 seconds, so the default can exceed the public limit and does not meet the task's pacing criterion. Set a safe default that enforces no more than six combined PSI/PM2.5 calls in each 10-second window (for example, a two-second inter-request delay or a shared rate limiter), and update the pacing test to assert the enforced limit. Optional API keys should not be required for this default behavior.
